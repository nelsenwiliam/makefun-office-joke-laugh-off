One original one-line office joke, entered in the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun. A judge model reads the jokes two at a time and keeps the funnier one — the funniest line takes the top place.

> I asked HR for a raise and they gave me a standing desk, so now I stand here underpaid.

## Run it

```sh
python3 main.py
```

The program writes the joke (a single line, 87 characters) to `/output/entry.txt` in the grader sandbox. Set `OUTPUT_DIR` to choose another output directory for local runs:

```sh
OUTPUT_DIR=./output python3 main.py
```

Pure Python standard library only — no third-party packages.
